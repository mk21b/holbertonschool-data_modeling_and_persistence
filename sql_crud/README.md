# SQL - CRUD Operations

This directory contains SQL files for the CRUD Operations project.
Each file contains one SQL query targeting a `books` table.

## Files
- `0-create_table.sql` - Create the books table
- `1-insert_data.sql` - Insert data
- `2-select_all.sql` - Select all rows
- `3-select_columns.sql` - Select specific columns
- `4-filter_by_genre.sql` - Filter by genre
- `4-filter_by_price.sql` - Filter by price
- `4-filter_with_and.sql` - Filter with AND
- `4-filter_with_or.sql` - Filter with OR
- `5-update_by_id.sql` - Update by id
- `5-update_by_condition.sql` - Update by condition
- `5-update_with_and.sql` - Update with AND
- `6-delete_by_id.sql` - Delete by id
- `6-delete_by_condition.sql` - Delete by condition
- `6-delete_with_and.sql` - Delete with AND
- `7-order_by_price_asc.sql` - Order by price ascending
- `7-order_by_year_desc.sql` - Order by year descending
- `7-limit_results.sql` - Limit results
- `7-order_and_limit.sql` - Order and limit
- `8-count_books.sql` - Count books
- `8-average_price.sql` - Average price
- `8-max_stock.sql` - Max stock
- `8-total_stock.sql` - Total stock
- `8-min_price.sql` - Min price
- `9-count_by_genre.sql` - Count by genre
- `9-average_price_by_genre.sql` - Average price by genre
- `9-total_stock_by_genre.sql` - Total stock by genre
- `9-count_by_author.sql` - Count by author
- `10-select_tech_books.sql` - Select tech books
- `10-increase_stock.sql` - Increase stock
- `10-delete_zero_stock.sql` - Delete zero stock
- `10-cheapest_available.sql` - Cheapest available
- `10-stock_by_genre.sql` - Stock by genre
- `10-average_price_by_genre.sql` - Average price by genre
